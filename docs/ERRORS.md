*an option value that is not a number is a usage error (exit code 2)*

## E0311

**Severity:** error · **Phase:** check

Unconditional recursion: a function calls itself, or a group of functions call each other in a cycle, and no call in the cycle sits under an `if`, a `match` case or the right side of `and` / `or` / `implies`. Whenever the function runs to that call it makes it, so it can never return. `cycle` lists the functions in call order with the line of the call that leads to the next. Put the recursive call in a branch and add a base case that returns without recursing. The check is deliberately conservative: it never flags a function that can terminate, but it misses some endless recursion (the fuel and depth limits catch those at run time).

*total calls itself in an argument of an unconditional `return`, so it has no base case*

Broken (`catalog/E0311/broken.zehn`):

```zehn
fn total(n: Int) -> Int
  example total(1) == 1
do
  return 1 + total(n - 1)
end fn

fn safe_total(n: Int) -> Int
  example safe_total(3) == 3
do
  if n <= 0 then
    return 0
  else
    return 1 + safe_total(n - 1)
  end if
end fn
```

Fixed (`catalog/E0311/fixed.zehn`):

```zehn
fn total(n: Int) -> Int
  example total(3) == 3
do
  if n <= 0 then
    return 0
  else
    return 1 + total(n - 1)
  end if
end fn
```

## E0312

**Severity:** error · **Phase:** check

A zero divisor is still E0505. There is no explicit name for the floor remainder `%`; for a positive divisor int.rem_euclid gives the same value.

```zehn

end fn
```
